# Análise de Seguros com Power BI

Projeto desenvolvido para estudo e prática de análise de dados utilizando SQL e Power BI.

## Objetivos do Projeto

- Criar indicadores operacionais e comerciais;
- Desenvolver dashboards analíticos;
- Praticar consultas SQL;
- Gerar insights para tomada de decisão;
- Simular análises reais do setor de seguros.

## Indicadores Analisados

- Receita total;
- Quantidade de apólices;
- Clientes ativos;
- Taxa de cancelamento;
- Sinistros por período;
- Performance operacional;
- Receita por categoria.

## Ferramentas Utilizadas

- Power BI
- SQL
- Excel
- GitHub
